# 🎬 Projeto 4: Página de Filme

Quarto projeto do curso da **EBAC**, desenvolvido por [DiegoNT1](https://github.com/DiegoNT1).

Este projeto consiste na criação de uma **página dedicada a um filme**, com layout visual moderno e foco na apresentação de conteúdo cinematográfico utilizando **HTML**, **CSS** e um pouco de **JavaScript**.

🔗 **Visualize online:**  
👉 [https://projeto-4-filme-five.vercel.app](https://projeto-4-filme-five.vercel.app)

---

## 🎥 Visão Geral

A página apresenta um filme com os seguintes elementos:

- 🖼️ Imagem de destaque (capa/poster)
- 📝 Sinopse ou descrição
- 📅 Informações como data de lançamento, gênero, duração etc.
- 🎞️ Trailer (embed do YouTube, se aplicável)
- 🎨 Design estilizado com foco na estética cinematográfica

---

## 🚀 Tecnologias Utilizadas

- **HTML5** – estrutura semântica
- **CSS3** – design visual e responsividade
- **JavaScript** – interações básicas (caso aplicável)
- **Fontes e ícones personalizados** – para estilo imersivo

---

## 📁 Estrutura do Projeto

```bash
Projeto_4_Filme/

├── img/
```
